감정 정의 카드 — 헷갈리면 펼쳐 보세요 (판단 순서: 극성 → 활성도 → 세부 톤)

질문은 하나: “이 이미지를 보며 틀고 싶은 음악은 어떤 감정인가?” 이미지 속 사람의 감정이 아니라, 보는 사람에게 일어나는 분위기를 고릅니다.

판단 순서: 극성(밝은가·어두운가) → 활성도(끌어올리는가·가라앉히는가) → 세부 톤(아래 구분 질문)

감정핵심 느낌시각 단서이런 경우는 다른 감정
happy 행복밝고 따뜻한 기쁨, 미소웃는 얼굴, 햇살, 생일·소풍, 따뜻한 색속도감·흥분이 주인공이면 energetic
energetic 활기들뜸, 에너지, 흥분공연·군중, 춤, 운동, 네온·강한 대비, 움직임분노·위협이 느껴지면 angry, 잔잔한 미소면 happy
calm 평온현실적인 고요·평온·정돈잔잔한 물, 책·차, 선명한 풍경, 자연광빛이 비현실적이거나 흐릿하면 dreamy, 쓸쓸하면 melancholy
romantic 로맨틱설렘, 애정, 두 사람커플, 꽃, 촛불, 노을 데이트, 핑크·레드 톤사람·애정 요소 없이 예쁘기만 하면 calm/dreamy
dreamy 몽환몽환, 비현실, 떠 있는 느낌파스텔, 안개, 빛 번짐(보케), 우주·별, 초현실선명하고 현실적이면 calm, 어둡고 처지면 melancholy
melancholy 우울/쓸쓸아련함·그리움, 조용하고 아름다운 슬픔저채도, 흐린 하늘, 빈 공간, 비 오는 창, 역광눈물·상실이 또렷하면 sad, 긴장·위협이면 angry
sad 슬픔상실, 고통, 비탄우는 얼굴, 장례·이별, 무너진 모습, 시든 꽃슬픔이 아름답고 조용하면 melancholy
angry 분노분노, 긴장, 위협, 제어 안 되는 힘불·폭발, 폭풍우, 강렬한 붉은·검은 톤, 일그러진 얼굴어둡지만 조용하고 내려앉으면 melancholy

헷갈릴 때는 위에서부터 차례로:

  1. 힘·움직임·위협(불, 폭풍, 강한 붉은색, 일그러진 얼굴)이 있는가? 예 → angry / 아니오 → melancholy
  2. 눈물·이별·상실이 직접 보이거나, 보면 가슴이 아픈가? 예 → sad / 아니오 → melancholy
  3. 두 사람·애정의 대상(커플, 꽃, 촛불)이 중심인가? 예 → romantic / 아니오 → calm / dreamy / melancholy
  4. 사람의 미소·축하·놀이가 중심인가? 예 → happy / 아니오 → calm
  5. 분위기가 '신나서 몸이 움직이는' 쪽인가(군중, 춤, 속도감)? 예 → energetic / 아니오 → happy
  6. 빛·색이 현실에서 보기 힘든가(파스텔, 번짐, 안개, 초현실)? 예 → dreamy / 아니오 → calm
  7. 조용함이 쓸쓸하고 허전한가(흐린 하늘, 빈 공간, 저채도)? 예 → melancholy / 아니오 → calm

어느 감정도 아니면 0(건너뛰기). 억지로 고른 라벨은 모델에 노이즈가 됩니다.

이 이미지에 어울리는 노래의 감정을 고르세요. 키보드 1~8 = 감정, 0 = 애매함(건너뛰기), ← → 이동
